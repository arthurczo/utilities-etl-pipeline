# Contributing

Contributions are welcome. Keep changes scoped, typed and covered by focused tests.

1. Create a branch from `main`.
2. Run `python -m pytest -q` and `python -m compileall -q src dags scripts dashboard`.
3. Update documentation when behavior or configuration changes.
4. Open a pull request describing the engineering rationale and validation.

Do not commit generated data, credentials, local checkpoints, or recordings containing sensitive information.
